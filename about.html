SPEC

“警告UI + 端末ログ + 工業パネル”の抽象表現で統一する。

やっていること

  • CSS変数で配色を統一（黒基調 / 警告赤 / 警告橙）
  • スキャンライン/ノイズ/六角パターンはCSSのみ（画像不要）
  • 共通JSで時計・SFX・トースト・端末コマンド

権利面の注意（公開する場合）

  • 公式ロゴ/キャラ画像/そのままの画面UI素材は使わない
  • 雰囲気は「形・配色・情報密度」で出す

次にやると強い拡張

  1. FILES_DB を JSON 化して、ページ追加のたびに app.js を触らなくて済むようにする
  2. 復号コンソールの状態を theater / pillar ごとに保存し、再訪時に復元する
  3. LIVE CAM に複数画像・動画ソースを差し込み、本当の監視UIに近づける
